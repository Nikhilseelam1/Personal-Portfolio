Mini-GPT from Scratch using PyTorch

Built a GPT-style Transformer completely from scratch, focusing on understanding the internal mechanics of Large Language Models, including attention, decoding strategies, and pretrained weight loading.

View Code

Project Overview

This project implements a GPT-style autoregressive Transformer model entirely from scratch using PyTorch, without relying on high-level libraries such as Hugging Face for model definition. The goal of this project was to gain a deep, practical understanding of Large Language Model internals and training mechanics.

The model includes custom implementations of self-attention, multi-head attention, Layer Normalization, GELU activation, positional embeddings, and feed-forward networks. A complete training loop was built from the ground up, enabling full control over forward and backward passes.

An autoregressive text generation pipeline was developed using top-k sampling and temperature scaling to control output diversity during inference. Additionally, GPT-2 pretrained weights were manually loaded by mapping QKV projections, feed-forward layers, and normalization parameters, demonstrating a strong understanding of model weight structures.

This project highlights strong fundamentals in Transformer architectures, LLM inference mechanics, and low-level model engineering, making it highly relevant for modern AI and NLP roles.
