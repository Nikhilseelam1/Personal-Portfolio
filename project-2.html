Sign Language Detection using YOLOv5

An end-to-end real-time object detection system for American Sign Language (ASL) recognition, built using YOLOv5 and a modular, production-ready machine learning pipeline.

View Code

Project Overview

This project implements a complete end-to-end object detection system for American Sign Language (ASL) recognition using YOLOv5. The solution covers the entire machine learning lifecycle, from data ingestion and validation to model training and real-time inference.

A large classification-based ASL dataset was converted into a YOLO-compatible object detection format by generating bounding boxes and annotation files. A robust data validation pipeline was designed to ensure label consistency, image integrity, and correct dataset structure before training.

The detection model was trained using transfer learning with pretrained YOLOv5 weights, enabling faster convergence and improved performance. The trained model predicts bounding boxes, class labels, and confidence scores in a single forward pass, making it suitable for real-time applications.

The system was designed with a modular, pipeline-driven architecture, allowing easy experimentation, reproducibility, and scalability. An interactive inference interface was built to perform real-time sign detection using live camera input or images, demonstrating practical usability in real-world scenarios.
