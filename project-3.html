Chest Disease Classification using MLflow & DVC

An end-to-end deep learning system for chest disease classification, built with production-grade MLOps practices including experiment tracking, data versioning, and reproducible pipelines.

View Code

Project Overview

This project implements a complete deep learning pipeline for chest disease classification using Convolutional Neural Networks (CNNs). The objective was to build a production-ready medical imaging system that follows real-world MLOps best practices rather than a simple experimental model.

The pipeline was designed using a modular architecture covering data ingestion, validation, preprocessing, model training, evaluation, and inference. Each stage is decoupled, making the system easy to maintain, extend, and debug.

Data and model versioning were handled using DVC, ensuring full reproducibility of experiments across different runs and environments. All training experiments, hyperparameters, and evaluation metrics were tracked using MLflow, enabling systematic comparison of model performance.

The project also includes artifact management, structured logging, and robust error handling, making it suitable for real-world deployment scenarios. This work demonstrates strong skills in both deep learning and applied MLOps workflows.
